# 牌局积分助手 (微信小程序版)

一款专为线下打牌、桌游设计的实时记账与积分统计小程序。通过微信云开发（CloudBase）实现多人高并发的实时数据同步。

## 🌟 功能特性

- **🏠 房间管理**：支持创建房间、生成房间二维码，其他玩家扫码或输入 6 位房间号即可快速加入。
- **📝 快捷记账**：支持批量支出/收入记账，自动进行“零和验证”，避免错账。包含快捷台费（台面费）扣除功能。
- **⚡ 实时同步**：基于云开发实时数据推送机制，任意一人提交账目，全员屏幕瞬间同步更新流水和总分。
- **🖼️ 个性化资料**：支持自定义昵称和头像，头像会自动居中剪裁并压缩上传至云存储。
- **📊 数据统计**：首页展示个人历史战绩（总局数、胜率、累计得分等），房间内提供直观的对局明细和流水历史。
- **💸 紧凑结算**：游戏结束后，一屏全览所有玩家的最终盈亏情况，正红负绿，清晰直观。

---

## 🛠️ 技术栈

- **前端**：原生微信小程序 (WXML, WXSS, JS)
- **后端**：微信云开发 CloudBase (云函数、云数据库、云存储)
- **并发优化**：采用“Pull-on-Push”策略（仅单点监听玩家集合，按需拉取流水集合），完美适配基础版套餐的低 WebSocket 连接数限制。

## 🚀 部署与运行指南

### 第一步：导入项目
1. 下载或 Clone 本项目代码。
2. 打开 **微信开发者工具**。
3. 选择“导入项目”，目录选择本项目根目录（`jifen_2`）。
4. 填入你自己的 **AppID**（非常重要，云开发依赖真实 AppID）。

### 第二步：开通云开发环境
1. 点击开发者工具顶部的 **“云开发”** 按钮。
2. 按照提示开通云开发服务（基础版免费）。
3. 复制你的**环境 ID**。
4. 打开项目中的 `app.js`，找到 `wx.cloud.init`，将 `env` 替换为你自己的环境 ID。

### 第三步：初始化数据库集合
在云开发控制台 -> **数据库** 中，手动创建以下三个集合（无需设置字段，云数据库为文档型会自动生成）：
- `Rooms` (记录房间信息、台面费)
- `Players` (记录房间内的玩家列表和实时总分)
- `Rounds` (记录每一笔记账的流水明细)

### 第四步：部署云函数
1. 在开发者工具左侧目录树中，展开 `cloudfunctions` 目录。
2. 右键点击 `room-manager` 文件夹。
3. 选择 **“上传并部署：云端安装依赖 (不上传node_modules)”**。
4. 等待部署成功提示。

### 第五步：编译预览
点击开发者工具顶部的 **“编译”**，即可在模拟器中看到大厅页面。你可以使用手机微信扫描预览二维码进行真实环境测试。
